Engenharia de Prompt. Prompts com contexto, tarefa, formato e restrições bem definidos, para respostas que dá para usar de verdade.

    •

    •

    • 
      

      

        

          
prompt 1 · cenários de teste

          
Contexto: Sou QA e vou validar a API de cadastro de um sistema.
Tarefa: Gere casos de teste a partir dos critérios de aceite abaixo.
Formato: Tabela com ID, cenário, pré-condição, passos e resultado esperado.
Restrições: Inclua casos negativos e de borda; não invente regras que não estejam nos critérios.

Critérios:
- E-mail deve ser único
- Senha com no mínimo 8 caracteres

        

        

          
prompt 2 · testes de API com Playwright

          
Contexto: Tenho uma coleção de requests no Postman de um endpoint de cadastro.
Tarefa: Converta os cenários em testes de API com Playwright (TypeScript).
Formato: Um arquivo .spec.ts com test.describe, um test por cenário e asserts de status e corpo.
Restrições: Não use dados reais; mantenha a URL base e o token em variáveis de ambiente.

        

        

          
prompt 3 · relatório de bug

          
Contexto: Encontrei uma falha durante a validação de uma release.
Tarefa: Escreva um relatório de bug a partir das anotações abaixo.
Formato: Título, ambiente, passos para reproduzir, resultado atual, resultado esperado, evidências e impacto.
Restrições: Linguagem objetiva; não suponha causa raiz que eu não tenha informado.
